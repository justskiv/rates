# rates: published files

This branch holds the files served at `https://rates.tuzov.dev/v1/` and
mirrored by jsDelivr. The rates job commits `v1/**` here; `.nojekyll`,
`CNAME` and this README are set by hand and never touched by the job.

Format, sources, licenses and attribution: see the
[main branch README](https://github.com/justskiv/rates#readme).
Rates are reconciled from [Frankfurter](https://frankfurter.dev) and
[fawazahmed0/exchange-api](https://github.com/fawazahmed0/exchange-api);
[ExchangeRate-API](https://www.exchangerate-api.com) is used as a
cross-check vote only. Rates By Exchange Rate API.
